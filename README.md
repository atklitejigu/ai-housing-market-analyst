# ai-housing-market-analyst
End-to-end mortgage analytics pipeline using HMDA data with logistic modeling, disparity analysis, and automated insight generation.
## Data
Raw and processed HMDA files are not included because of their size. Download the 2024 HMDA data for the DC metro area from the FFIEC Data Browser at https://ffiec.cfpb.gov/data-browser/ and place it in data/raw/.
